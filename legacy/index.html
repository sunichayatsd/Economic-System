1. ไฟล์ Zip Event ลาก Excel ที่ export จาก Zipevent มาวาง หรือ ยังไม่ได้ใส่ไฟล์ · ไฟล์อ่านในเบราว์เซอร์นี้เท่านั้น ไม่ถูกส่งขึ้นเซิร์ฟเวอร์
2. ช่วงเวลาที่แอดรัน ลากไฟล์ export จาก Ads Manager (breakdown Time of day) มาวาง หรือ หรือแก้ช่วงเวลาเอง ↓

"ขายช่วงที่แอดรัน" ไม่เท่ากับ "ยอดที่แอดสร้าง" — นับทุกออเดอร์ที่จ่ายเงินในชั่วโมงที่แอดมี impression จึงรวมคนที่ตั้งใจซื้ออยู่แล้วด้วย ถ้าแอดรันเกือบตลอด ตัวเลขนี้จะใกล้ยอดขายทั้งหมด ใช้เป็น "เพดาน" คู่กับตัวเลขที่พิสูจน์ได้ (ref code ad-) ซึ่งเป็น "พื้น"
